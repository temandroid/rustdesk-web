# RustDesk web client (open core build)

This `flutter/web/` directory is generated by `web-core/scripts/sync-to-flutter.mjs`.
Do not edit here; edit `web-core/web/` and re-run `npm run sync`.

`js/rustdesk-web-core.js` is the open TypeScript viewer core (relay-only MVP:
connect by ID, password login, WebCodecs video, mouse and keyboard).
